
# ¡Hola! Soy Hivor Araujo 👋

Soy estudiante de Ingeniería en Computación en la Escuela Superior Politécnica del Litoral (ESPOL). Me interesa el desarrollo de software y seguir mejorando mis conocimientos de programación mediante proyectos académicos y personales.

## Sobre mí

- 🎓 Actualmente estudio Ingeniería en Computación en ESPOL.
- 💻 He trabajado en proyectos de desarrollo web utilizando HTML, CSS y JavaScript.
- 🛠️ Tengo experiencia utilizando Git y GitHub para organizar y versionar mis trabajos.
- 📚 Me gusta aprender nuevas herramientas y poner en práctica lo que veo en clases.
  

## Tecnologías y herramientas

Estas son algunas de las tecnologías y herramientas que he utilizado durante mi formación y en el desarrollo de mis proyectos:

- **HTML:** lo he utilizado para estructurar páginas web, como el sitio del Parque Samanes y mi proyecto sobre videojuegos.
- **CSS:** me ha permitido trabajar en el diseño de páginas, aplicando colores, estilos y distribuciones para organizar el contenido.
- **Flexbox y CSS Grid:** los he practicado en EcoRuta, creando diferentes distribuciones de una misma página y adaptándolas a distintos tamaños de pantalla.
- **JavaScript:** lo he utilizado para agregar interactividad a páginas web, como en la carta digital para mamá y el proyecto de videojuegos.
- **Git y GitHub:** los utilizo para guardar versiones de mis proyectos, trabajar con ramas y registrar los cambios mediante commits.
- **GitHub Pages:** lo he utilizado para publicar proyectos web, como el sitio del Parque Samanes, y compartirlos mediante un enlace público.
